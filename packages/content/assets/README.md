# Assets

Placeholder-asset directories, referenced by relative path from `data/content-items/*.json` (`audioUrl`, `imageUrl`).

- `sprites/` — character, enemy, and vocabulary-card images. Empty for now; final art TBD per docs/phase-0-product-definition.md §29 (placeholder art strategy).
- `audio/` — native-speaker pronunciation clips and SFX. Empty for now.
- `icons/` — UI icons (inventory, equip slots, HUD).

Nothing in this repo depends on these files existing yet — Phase 5 wires up the content pipeline; Phase 6+ is where real placeholder art/audio lands.
